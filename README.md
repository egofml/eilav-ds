# EILAV DS

위탁판매 자동화를 다른 PC와 다른 ChatGPT/Codex 계정에서도 사용할 수 있게 만드는 프로젝트.

현재 상태: Excel 표 붙여넣기, 금지어 제거, 상품명 후보 삽입, 배송비 변경, Gemini 보조 검토용 다중 키 등록을 구현했다. 판매처 직접 연동과 Excel 자동 쓰기는 구현하지 않았다. 실키 Gemini 호출은 아직 검증하지 않았다.

웹앱 실행: `npm start` 후 http://127.0.0.1:5549 접속. ZIP의 `dist/index.html`을 직접 열 수도 있다. 사용 방법과 검증 범위는 [WEBAPP.md](WEBAPP.md)를 참고한다.

GitHub 저장소: https://github.com/egofml/eilav-ds (공개)

GitHub 가입 없이 받기: [ZIP 다운로드](https://github.com/egofml/eilav-ds/archive/refs/heads/main.zip)

## 다른 PC에서 받기

1. 위 ZIP 다운로드 링크를 연다. 공개 저장소이므로 GitHub 가입이나 초대가 필요 없다.
2. 내려받은 ZIP의 압축을 푼다.
3. Git을 사용하는 경우 ZIP 대신 아래 명령으로 받을 수 있다.

```sh
git clone https://github.com/egofml/eilav-ds.git
```

4. 본인 계정으로 로그인한 Codex에서 받은 프로젝트 폴더를 연다. README.md와 AGENTS.md를 읽고 작업을 이어가도록 요청한다.
5. 웹앱에서 본인의 금지어 파일과 상품 표를 불러온다. Gemini를 사용할 사람만 본인의 API 키를 등록한다.

Git으로 받은 프로젝트는 로컬 변경을 정리한 뒤 프로젝트 폴더에서 `git pull --ff-only`로 업데이트한다. ZIP으로 받은 경우 새 배포본을 별도 폴더에 풀고 개인 설정과 데이터는 보존한다.

## 공유 구조

- 코드, 업무 절차, Codex 프로젝트 지침, 설정 예시를 Git 저장소에 함께 관리한다.
- 배포 경로는 GitHub 저장소 또는 검토된 배포 ZIP을 우선 고려한다.
- 사용자는 자기 PC에 프로젝트를 받고 자기 Codex 계정으로 폴더를 연다.
- 판매처·공급처 로그인, API 키, 연결 권한은 사용자별로 설정한다.
- 기존 대화나 개발자 개인 메모리에 의존하지 않도록 실행 절차와 결정 사항을 저장소에 기록한다.
- 재사용할 업무가 확정되면 `.agents/skills/`에 프로젝트 스킬을 제공한다. 여러 프로젝트에서 설치해 쓸 필요가 생기면 플러그인 패키징을 검토한다.

## 첫 작업 흐름: Excel 복사 → 분석·수정 → Excel 복귀

사용자 요구: 열려 있는 Excel에서 일부 내용을 복사해 작업 공간에 넣고, 분석·수정한 데이터를 원래 Excel로 돌려보낸다. 내려받아 Codex에서 사용하는 방식과 웹앱 제공을 고려한다.

제안하는 첫 구현 흐름:

1. Excel에서 수정할 표 범위를 복사한다. 원래 시트와 붙여넣을 시작 셀을 확인한다.
2. 작업 공간에 붙여넣고 열 제목과 행 수를 확인한다.
3. 수정 대상 열과 원하는 작업을 지정한다.
4. 원본과 수정본을 나란히 보고 변경 내용을 확인한다.
5. 수정 결과를 복사해 원래 Excel의 지정한 범위에 붙여넣는다.

행·열 순서와 크기는 기본적으로 유지한다. 정렬이나 행 삭제가 필요하면 별도 작업으로 구분한다. 빈 셀, 셀 안의 줄바꿈, 앞자리 0이 있는 상품 코드를 고려한다. 수식이 있는 범위는 값만으로 덮어쓰지 않도록 수정 대상과 구분한다. 일반 텍스트 복사만으로 Excel 수식·서식·병합 상태가 모두 보존되는 것으로 가정하지 않는다.

웹앱의 초기 반환 방식은 사용자가 복사·붙여넣기하는 방식이다. 열려 있는 Excel에 직접 쓰는 기능은 별도 Excel 연결이 필요하다. 웹앱에서 AI 분석을 실행하려면 별도 모델 연결과 인증·비용 구조를 정해야 하며, 이 기능은 현재 구현되어 있지 않다.

확정된 첫 기능: 29개 열의 원본 순서를 보존하면서 상품명·키워드 금지어 삭제, 배송비·반품배송비 각각 500원 인상, 기존 키워드 기반 상품명 추가 제안. API 없는 기본 편집과 선택적인 Gemini 일반 지식 검토를 제공한다. KIPRIS 자동 조회는 연결하지 않았다.

## 코드 공유와 데이터 연동

기본은 같은 자동화를 각자의 계정과 데이터로 독립 실행하는 방식이다. 상품·주문·재고를 여러 사용자가 함께 다뤄야 한다면 별도 공유 저장소 또는 서버와 사용자별 권한을 설계한다. GitHub 코드 업데이트는 판매 데이터 동기화를 의미하지 않는다.

## 구현 요구사항

1. 특정 PC의 절대 경로, 개발자의 로그인 세션 및 개인 계정에 의존하지 않는다.
2. 사용자 데이터와 인증정보는 코드 밖에 보관한다. 저장소 내부에서 필요한 로컬 파일은 `local/`에 둔다.
3. 초기 설정 안내, 필수 도구 검사, 설정 예시, 샘플 데이터 실행을 제공한다.
4. 업데이트 시 사용자 설정과 작업 데이터를 보존한다.
5. 외부 변경 전 미리보기와 중복 실행 방지, 실행 결과 기록을 구현한다.
6. 실제 다른 PC와 다른 계정으로 설치부터 결과 확인까지 검증한 뒤 이식성 완료로 보고한다.
7. 배포 파일은 명시적인 허용 목록으로 구성하고 인증정보·개인정보 포함 여부를 점검한다. `.gitignore`만으로 ZIP 배포 보호를 대신하지 않는다.
